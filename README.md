# JuliadaMilena

# Loja de Produtos Personalizados

Este é um site moderno para a **JuliadaMilena**, apresentando produtos, serviços e informações de contato.  
O site tem como objetivo mostrar o portfólio da marca e facilitar que clientes conheçam os produtos e façam encomendas.

---

##  Tecnologias Utilizadas
- **HTML5** — Estrutura das páginas  
- **CSS3** — Estilos, cores e layout responsivo  
- **JavaScript** — Funcionalidades interativas  
- **Git & GitHub** — Controle de versão  
- **GitHub Pages** — Hospedagem gratuita  

---

## Desenvolvimento do Projeto

1. Planejamento das seções do site:
   - Página inicial com destaque para produtos
   - Sobre a marca
   - Galeria de produtos
   - Seção de contato e encomendas
   - Rodapé com redes sociais e informações

2. Estruturação em HTML:
   - Tags semânticas (`header`, `section`, `footer`)
   - Links internos para navegação rápida

3. Design e responsividade com CSS:
   - Cores e fontes personalizadas da marca
   - Layout adaptável a dispositivos móveis
   - Efeitos visuais para botões e imagens

4. Funcionalidades JavaScript:
   - Validação do formulário de contato
   - Interações visuais para botões e scroll

5. Testes locais:
   - Verificação de responsividade
   - Teste do formulário
   - Ajustes de layout e imagens

## Testando Localmente

###  Abrir diretamente no navegador
- Clique duas vezes em `index.html` para abrir.

###  Usando VS Code + Live Server
1. Instale a extensão **Live Server**  
2. Clique com o botão direito em `index.html`  
3. Selecione **Open with Live Server**

###  Android (Web Server for Android)
1. Coloque os arquivos na pasta `www`  
2. Inicie o servidor  
3. Acesse pelo navegador do dispositivo

##  Hospedagem no GitHub Pages

### Criar repositório
- GitHub → **New Repository**  
- Nome: `JuliadaMilena`  
- Público → Create repository  

### Enviar os arquivos
- Add file → Upload files  
- Enviar todos os arquivos → Commit changes  

###  Ativar GitHub Pages
1. Settings → **Pages**  
2. Source → **Deploy from a branch**  
3. Branch → **main**, Folder → **root**  
4. Salvar
